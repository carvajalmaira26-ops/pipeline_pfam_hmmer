El presente repositorio contiene el desarrollo de un pipeline bioinformático diseñado para la identificación y asignación de familias de proteínas Pfam a un conjunto específico de secuencias proteicas obtenidas desde la base de datos UniProt. El análisis se realiza mediante el uso de perfiles ocultos de Markov (HMM), implementados a través de la herramienta HMMER. Con el fin de optimizar el procesamiento computacional, se trabaja únicamente con un subconjunto seleccionado de familias Pfam, lo cual permite reducir la complejidad del análisis y enfocarlo en categorías funcionales específicas. El objetivo general del proyecto es determinar la relación funcional de un conjunto de proteínas mediante la identificación de dominios conservados presentes en sus secuencias.

El objetivo principal consiste en identificar las familias de proteínas Pfam asociadas a un conjunto de proteínas UniProt utilizando herramientas bioinformáticas basadas en modelos HMM. Para ello, se seleccionó un conjunto reducido de familias Pfam con el fin de disminuir el tiempo de procesamiento y enfocar el análisis en grupos funcionales relevantes. Las familias incluidas corresponden a Protein_kinase, Pkinase_Tyr, Ras, SH2, SH3_1, zf-C2H2, Homeobox, HTH_1, bZIP_1, Myb_DNA-binding, RRM_1, DEAD, KH_1, dsrm, ABC_tran, MFS_1, Ion_trans, HlyD, Aminotran_1_2, Aldedh, TIM, NAD_binding_1, GST_C_family, WD40, Ank, TPR_1, LRR_1, HSP70, HSP20, DnaJ, Response_reg, HisKA, Peptidase_M16, Sigma70_r2, Immunoglobulin, EGF, Cadherin y Fibronectin.

El conjunto de proteínas analizadas corresponde a identificadores UniProt provenientes de diferentes organismos, entre los cuales se incluyen P00519, P42684, P12931, P06241, P07947, Q06187, P43403, P43405, P62993, P01112, P01116, P01111, P04049, P31749, P28482, P27361, P00533, P21802, P16234, P12956, P29353, P42681, P35222, P62937, P29317, P08047, P15056, P40763, P42224, P15924, P10242, P19838, P11473, P61244, Q9Y2T1, P08107, P0A6Y8, P0A6W5, P0A9Q7, P0A799, P0A7Y4, P0A8V2, P39451, P11142, P13569, P22681, P98160, P12814, Q92793 y Q13485.

El pipeline fue desarrollado utilizando HMMER versión 3.4, disponible en http://hmmer.org/, junto con la base de datos Pfam versión 38.2, accesible en https://ftp.ebi.ac.uk/pub/databases/Pfam/releases/Pfam38.2/. El análisis puede ser implementado en Python o R, dependiendo de la elección del usuario, y se ejecuta en un entorno Linux, preferiblemente Ubuntu. El flujo de trabajo está organizado en módulos independientes que incluyen la preparación de datos de entrada a partir de UniProt, la selección del subconjunto de familias Pfam, la ejecución de búsquedas de dominios proteicos mediante HMMER, el procesamiento y filtrado de resultados, la asignación de familias a cada proteína y la generación de resultados finales que incluyen tanto proteínas con asignación funcional como aquellas sin coincidencias significativas.

Dentro del pipeline se implementa programación orientada a objetos para representar la información de cada proteína de manera estructurada. Se define una clase Protein que almacena el identificador UniProt, la secuencia proteica y las familias asignadas, además de incluir métodos para agregar familias y generar un resumen de la información asociada a cada proteína. Esta estructura permite una organización más clara y facilita el análisis posterior de los resultados obtenidos.

El repositorio se encuentra organizado en diferentes carpetas con el fin de mantener una estructura clara y reproducible. La carpeta data contiene los archivos de entrada, los cuales no se incluyen en el repositorio mediante el uso de .gitignore. La carpeta scripts contiene los scripts principales del pipeline, mientras que src contiene las clases y funciones utilizadas en el análisis. La carpeta results almacena los resultados generados durante la ejecución del pipeline, y docs incluye documentación complementaria del proyecto.

Con el objetivo de mantener el repositorio limpio y enfocado únicamente en el código, se implementa un archivo .gitignore que excluye bases de datos completas de Pfam, archivos intermedios de ejecución y resultados temporales del análisis.

Como referencia metodológica, se utilizan la base de datos Pfam y la herramienta HMMER, ampliamente utilizadas en bioinformática para el análisis de dominios proteicos, junto con la base de datos UniProt como fuente de secuencias proteicas.

Este proyecto fue desarrollado en el marco de formación en biología con el propósito de aplicar herramientas bioinformáticas en el análisis de familias proteicas mediante modelos estadísticos, integrando programación, bases de datos biológicas y análisis funcional de proteínas.
